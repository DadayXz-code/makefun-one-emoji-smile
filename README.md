One warm hug, in a single emoji: a hugging face with open arms, picked to make a stranger smile at first glance. The program writes exactly that one emoji to `/output/entry.txt` — nothing else, no words, no caption. Deterministic and dependency-free: the same emoji, every run.

## Run it

```sh
python3 main.py
```
